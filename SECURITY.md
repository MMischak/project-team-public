# Security

This project is an early alpha. Live work depends on a compatible, verified native permission profile and existing Codex subscription authentication. Failed verification must never enable unrestricted execution or an API-billing fallback.

Do not publish credentials, account details, raw session transcripts, private project files or unredacted diagnostics in an issue.

For a vulnerability, use this repository's **Security → Report a vulnerability** private reporting flow when available. If it is unavailable, open a minimal issue asking for a private reporting channel without including exploit details or sensitive data.

Public-source checks cover the tracked publication tree and synthetic assets. They do not audit the contents of your own projects or guarantee that a future checkpoint selection is safe to publish. Review exports and repository visibility before confirming them.
