# Direction

The goal is an AI team whose capability fits the work, with transparent usage and outputs people can inspect.

## Implemented

User-selected members/models/effort, manager proposals, sequential tasks, captured deliverable handoffs, independent review, milestone steering, meetings, token accounting, recovery, GitHub checkpoints and storage controls.

## Next questions to validate

- **Task-fit suggestions:** explain which responsibility, model capability and reasoning effort suit a task before the user assigns it.
- **Measured efficiency:** compare token usage, latency and output quality across capability choices and against a single-agent baseline.
- **Focused context:** send the information a task needs, with clear provenance and smaller handoffs where possible.
- **Broader deliverables:** improve preview and review for artifact types beyond text/source.
- **Portability:** verify execution/authentication/storage behavior across more platforms and runtime versions.

Automatic model routing, price optimization, guaranteed token savings and parallel work are not current features. Suggestions must keep the existing approval, privacy, recovery and budget boundaries.
